# ICM Ruby MD Python Maker

ICM Ruby MD Python Maker generates ICM Ruby scripts, Markdown documentation, and Python code from a single source description. The idea is to write the logic for a task once and get consistent, matching output in each of those three forms, rather than hand-maintaining separate versions that drift apart over time.

The project is built with Vite, TypeScript, React, shadcn-ui, and Tailwind CSS.
